# Approval Rules

The current assignment authorizes routine, reversible work inside the approved client-folder boundary. Do not ask a second time for every normal upload, folder, template copy, rename, in-client move, archive, or export needed to complete that assignment.

## Routine Work

Proceed when all of these are true:

- The assignment clearly calls for the action.
- The account, client code, source item, and destination are resolved.
- Source and destination are inside the same approved client folder tree.
- The action creates a new item or makes a reversible organizational change.
- The agent will verify the result and write a private receipt.

## Preview and Ask

Show a concise preview and obtain a clear approval before:

| Action | Preview must include |
|---|---|
| Overwrite or replace a file | Exact file ID, current name, expected replacement, known version when available, and recovery plan. |
| Trash important file or folder | Exact ID, current location, reason, and recovery plan. |
| Move or copy to another client | Source and destination client codes, IDs, locations, and reason. |
| Share outside normal client group | File ID, recipient/group, permission role, external status, invite-email behavior, and visibility impact. |
| Remove access | File ID, recipient/group losing access, and impact. |

Use this format:

```text
Action: [exact action]
Account: [account label]
Client: [client code]
Target: [name] | fileId: [id]
Current location: [folder]
Proposed result: [new location, replacement, or access change]
Recovery: [how it can be reversed]
Proceed? (yes/no)
```

## Jack’s Direct Approval

Require an explicit approval from Jack in the current request for:

- Public or “anyone with the link” sharing.
- Domain-wide or discoverable sharing.
- Ownership transfer.
- Bulk permission changes.
- Permanent deletion.
- Large cross-client moves or copies.

A broad instruction such as “clean up Drive” or “share the report” is not enough for these actions.

## Unclear Assignment

If the current assignment does not clearly authorize the requested Drive write, ask one focused question. Do not quietly widen scope, choose a client, substitute a file, replace content, or expose a link.
